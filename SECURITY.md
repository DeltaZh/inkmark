# Security Policy

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report security issues privately via [GitHub Security Advisories](https://github.com/OWNER/delta-ink/security/advisories/new) (replace `OWNER` with the repository owner once published).

We will acknowledge your report, investigate promptly, and coordinate disclosure. Thank you for helping keep delta-ink and its users safe.
