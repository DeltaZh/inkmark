# delta-ink v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 macOS 上交付 参考编辑器 式所见即所得 Markdown 编辑器 delta-ink（多标签、大纲、主题高兼容、图片、代码高亮、查找替换），并按 GitHub 开源项目标准组织仓库。

**Architecture:** Tauri 2 负责文件/主题/设置 IPC；React + TypeScript + Vite 承载 UI；TipTap 做 WYSIWYG，经 参考编辑器 DOM 适配层挂载用户主题 CSS（根节点 `#write`）。每个标签一份 Markdown 逻辑源，保存时从编辑器序列化回 `.md`。

**Tech Stack:** Tauri 2、Rust、React 18、TypeScript、Vite、TipTap 2、`@tiptap/pm`、`turndown` + `marked`（或等价 Markdown 往返）、Vitest、GitHub Actions（`macos-latest`）。

## Global Constraints

- 平台：第一版只保证 **macOS**
- 编辑形态：**真 WYSIWYG**，禁止左右分栏作为主编辑模式
- 主题：高兼容 参考编辑器 CSS；扫描 参考编辑器 目录 + 应用自有目录；同名时自有优先
- 应用自有主题目录：`~/Library/Application Support/delta-ink/themes`
- 参考编辑器 主题目录：`~/Library/Application Support/abnerworks.参考编辑器/themes`
- Bundle ID：`app.delta.ink`
- LICENSE：**MIT**
- 默认分支目标名：`main`（推送 GitHub 前从 `master` 重命名）
- Commit message：约定式前缀 + **中文**说明（如 `feat:新增主题扫描`）
- 第一版不做：文件树、导出 HTML/PDF、表格可视化编辑、公式、Mermaid、云同步、Win/Linux 打包
- 规格原文：`docs/superpowers/specs/2026-08-06-delta-ink-design.md`

- [ ] **Step 3: 实现 Settings 与磁盘读写**

```rust
use serde::{Deserialize, Serialize};
use std::fs;
use std::path::{Path, PathBuf};

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
#[serde(rename_all = "camelCase")]
pub struct Settings {
    pub default_theme: String,
    pub read_external_themes: bool,
    pub image_strategy: String,
}

impl Default for Settings {
    fn default() -> Self {
        Self {
            default_theme: "default".into(),
            read_external_themes: true,
            image_strategy: "assets_beside".into(),
        }
    }
}

pub fn settings_path(app_data: &Path) -> PathBuf {
    app_data.join("settings.json")
}

pub fn load_from_path(path: &Path) -> Result<Settings, String> {
    if !path.exists() {
        return Ok(Settings::default());
    }
    let raw = fs::read_to_string(path).map_err(|e| e.to_string())?;
    serde_json::from_str(&raw).map_err(|e| e.to_string())
}

pub fn save_to_path(path: &Path, settings: &Settings) -> Result<(), String> {
    if let Some(parent) = path.parent() {
        fs::create_dir_all(parent).map_err(|e| e.to_string())?;
    }
    let raw = serde_json::to_string_pretty(settings).map_err(|e| e.to_string())?;
    fs::write(path, raw).map_err(|e| e.to_string())
}
```

Commands 用 `tauri::AppHandle` 取 `path().app_data_dir()`，目录名对应 `delta-ink`。

- [ ] **Step 3: 实现扫描与路径校验**

```rust
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
#[serde(rename_all = "camelCase")]
pub struct ThemeInfo {
    pub id: String,
    pub name: String,
    pub path: String,
    pub source: ThemeSource,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
#[serde(rename_all = "lowercase")]
pub enum ThemeSource {
    参考编辑器,
    App,
    Builtin,
}

pub fn scan_theme_dirs(dirs: &[(&Path, ThemeSource)]) -> Vec<ThemeInfo> {
    use std::collections::HashMap;
    let mut map: HashMap<String, ThemeInfo> = HashMap::new();
    // 先 external 后 app 时：后写入覆盖。调用方应按 [external, app] 顺序传入，或在此规定 app 后扫。
    for (dir, source) in dirs {
        if !dir.exists() {
            continue;
        }
        let entries = match fs::read_dir(dir) {
            Ok(e) => e,
            Err(_) => continue,
        };
        for entry in entries.flatten() {
            let path = entry.path();
            if path.extension().and_then(|e| e.to_str()) != Some("css") {
                continue;
            }
            let name = path
                .file_stem()
                .and_then(|s| s.to_str())
                .unwrap_or("untitled")
                .to_string();
            let id = format!("{:?}:{}", source, name);
            map.insert(
                name.clone(),
                ThemeInfo {
                    id,
                    name,
                    path: path.to_string_lossy().into(),
                    source: source.clone(),
                },
            );
        }
    }
    let mut list: Vec<_> = map.into_values().collect();
    list.sort_by(|a, b| a.name.cmp(&b.name));
    list
}
```

`list_themes` command：解析 home 下两个固定相对路径；`read_external == false` 时跳过 参考编辑器 目录；始终包含内置 `default`（打包在 `src/styles/external-base.css`，source=`builtin`，path 可用特殊前缀 `builtin:default`）。

`read_theme_css`：若 path 为 `builtin:default`，返回内置 CSS 字符串；否则 `canonicalize` 后检查是否位于允许根目录之下。

```ts
export type OutlineItem = { level: number; text: string; id: string };

export function extractOutlineFromHtml(html: string): OutlineItem[] {
  const doc = new DOMParser().parseFromString(html, 'text/html');
  const nodes = doc.body.querySelectorAll('h1,h2,h3,h4,h5,h6');
  return Array.from(nodes).map((el, i) => ({
    level: Number(el.tagName.substring(1)),
    text: el.textContent?.trim() || '',
    id: el.id || `heading-${i}`,
  }));
}
```

```ts
export function extractOutlineFromEditorJson(doc: JSONContent): OutlineItem[] {
  const items: OutlineItem[] = [];
  const walk = (node?: JSONContent) => {
    if (!node) return;
    if (node.type === 'heading') {
      const level = Number(node.attrs?.level ?? 1);
      const text = (node.content ?? []).map((c) => c.text ?? '').join('');
      items.push({ level, text, id: `h-${items.length}` });
    }
    node.content?.forEach(walk);
  };
  walk(doc);
  return items;
}
```
