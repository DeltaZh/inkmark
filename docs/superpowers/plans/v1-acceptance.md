## 主题：目录、开关、导入

- [ ] 默认扫描 参考编辑器 主题目录与自有目录，列表去重且标注来源
- [ ] 设置中 **关闭「读取 参考编辑器 主题」** 后，列表仅显示自有 / 内置主题
- [ ] 重新 **开启** 后 参考编辑器 主题再次出现
- [ ] 工具栏「导入主题」打开系统文件选择器，可选任意路径的 `*.css`
- [ ] 导入后文件复制到 `~/Library/Application Support/delta-ink/themes`（同名覆盖），列表出现并可切换
- [ ] 主题 CSS 加载失败时回退内置默认主题并提示用户

## 核心功能（§6）

- [ ] 文件：新建 / 打开 / 保存 / 另存为；关闭未保存有确认
- [ ] 多标签：`⌘W` 关标签、`⌘S` 保存
- [ ] 大纲：随文档更新，点击跳转到对应标题
- [ ] 图片：拖拽或粘贴插入，保存到文档旁 `assets/` 相对路径
- [ ] 代码块：围栏语法高亮与主题协调
- [ ] 查找替换：当前文档内查找与替换（`⌘F`）
- [ ] 快捷键：`⌘B` / `⌘I` 粗斜体；`⌘⌥1`–`⌘⌥6` 标题级别
- [ ] 设置持久化：默认主题、`read参考编辑器Themes`、图片策略重启后保留

---

## 错误与边界（§7.2）

- [ ] 文件被外部修改：切回窗口提示「重新加载」或「保留内存版本」
- [ ] 参考编辑器 主题目录不存在：不致命报错，仅无外部主题
- [ ] 无写权限或路径失效：对话框说明，不静默失败

---

## 非目标（确认未实现即可）

- [x] 无文件树 / 文档库
- [x] 无导出 HTML / PDF
- [x] 无表格可视化编辑、数学公式、Mermaid
- [x] 无 Windows / Linux 打包（第一版仅 macOS）
